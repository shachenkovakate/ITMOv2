# E2E-проверки

Файл ведёт OpenCode. Обсудите с агентом содержание и проверьте предложенный diff. Все дополнения и исправления поручайте агенту в чате.

| Сценарий пользователя | Предусловия | Действие | Наблюдаемый результат | Подтверждение |
|---|---|---|---|---|
| Позитивный | LLM test double возвращает валидную структуру с одним доказуемым риском | Ревьюер отправляет допустимый diff | Ответ содержит `summary`, один risk с `file`, `line`, `evidence`, `risk` и массив `checks`; действий в GitHub нет | HTTP-ответ и журнал вызовов зависимостей |
| Негативный | LLM test double выбрасывает исключение | Ревьюер отправляет допустимый diff | Запрос завершается контролируемым ответом; формат и HTTP-статус фиксируются после согласования контракта | HTTP-ответ, ограниченное время и отсутствие необработанного traceback |
| Граничный | Подготовлен diff длиной 20 001 символ с тестовым token | Ревьюер отправляет запрос | Получен HTTP 413; LLM не вызван, тестовый token не появился в логах | Статус ответа, `call_count == 0`, перехваченные логи |
