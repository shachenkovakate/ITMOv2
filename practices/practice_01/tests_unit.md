| Требование или правило | Что проверяем изолированно | Вход | Ожидаемый результат | Подтверждение |
|---|---|---|---|---|
| `SEC-1` | Редактирование token | `token=abc123` внутри diff | В prompt есть `[REDACTED]`, значения `abc123` нет | Аргумент вызова mock LLM |
| `SEC-1` | Редактирование password и private key | Тестовый пароль и блок `BEGIN PRIVATE KEY` | Оба значения заменены до вызова LLM | Аргумент вызова mock LLM |
