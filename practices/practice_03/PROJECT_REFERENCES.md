Подготовлены рабочим агентом до запуска пяти вопросов. Этот файл находится вне временных тестовых окружений и локальной модели не передаётся. Все пути ниже относительно `lab/demo/`.

|---|---|---|---|
| 1 | Как запустить тесты? Укажи файл-источник. | Выполнить `make test` из каталога учебного проекта. Цель запускает `python3 -m unittest -v`. | `README.md:6`; `Makefile:2–3`. Из `lab/` команда также работает через `lab/Makefile:4–5`. |
| 2 | Что будет при пустом имени подписчика? Подтверди кодом. | Для пустой строки и строки только из пробелов `subscribe` выбрасывает `ValueError("empty name")`; добавления подписчика не происходит. | `service.py:4–7`: проверка `not name.strip()` и исключение перед `subscribers.add`; тест строки из пробела — `test_service.py:13–15`. |

| 4 | Какая CI-система запускает тесты?
