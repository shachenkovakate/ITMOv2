# Notify Mini: требования практики 4

Исходное поведение: subscribe(name) обрезает пробелы, добавляет имя в множество в памяти и возвращает {"subscribed": True}. Повтор не создаёт дубликат; пустое имя или пробелы вызывают ValueError("empty name"). Хранение после перезапуска не требуется.

## Фича A: отписка

Добавить unsubscribe(name). Имя обрезается так же, как при подписке. Для пустого имени или пробелов — ValueError("empty name"). Существующее имя удаляется, ответ {"unsubscribed": True}. Неизвестное имя и повторная отписка возвращают {"unsubscribed": False}, без изменения остальных подписчиков.

Приёмка: успешная отписка, неизвестное имя, повтор, пробелы вокруг имени, пустое имя; исходные сценарии subscribe проходят.

## Фича B: список подписчиков

Добавить list_subscribers(), возвращающую новый список имён, отсортированный по стандартному порядку строк Python. Пустое множество даёт []. Изменение возвращённого списка не изменяет хранилище. После subscribe/unsubscribe список отражает текущее состояние.

Приёмка: пустой список, сортировка, отсутствие дубликатов, независимость списка от хранилища, совместный сценарий подписки и отписки. Фича B выполняется в отдельном git worktree после коммита A; проверяется объединённый результат.
