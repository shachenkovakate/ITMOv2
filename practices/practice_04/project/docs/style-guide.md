# Стиль Notify Mini

1. Используй стандартную библиотеку Python и небольшие функции в `service.py`;
   для этого сервиса не нужен framework или дополнительный слой классов.
2. Храни подписчиков в существующем множестве `subscribers` в памяти. Проверяй
   входное имя до изменения состояния, обрезая края строки через `strip()`.
3. Сохраняй точные ответы и ошибки из `docs/requirements.md`: ключи словарей,
   значения bool и сообщение `empty name` являются частью контракта.
4. Пиши поведенческие тесты на `unittest` в `test_service.py`: очищай множество
   в `setUp`, проверяй ответ функции и состояние, используй `subTest` для вариантов входа.
5. Сначала покажи падение нового теста, затем реализацию и успешный
   `sh scripts/check.sh`. Подтверждения реальных вызовов сохраняй в `evidence/`.

## Пример: отписка не затрагивает другого подписчика

```python
def test_unknown(self):
    subscribe("Bob")
    self.assertEqual(service.unsubscribe("Ann"), {"unsubscribed": False})
    self.assertEqual(subscribers, {"Bob"})
```
