| Вопрос | UI | Логика | Предложение общего контракта |
|---|---|---|---|
| Единица длины | Unicode code points | То же | Совпадает; уточнили textarea/CRLF |
| Частичный учебный hunk | Принимать | Принимать, координаты от начала | Совпадает; не выдумывать отсутствующие строки |
| checks | Пустой массив допустим | Требуется 1–10 | Минимум одна полезная проверка |
| Evidence по правилу | Строка и объяснение правила, координаты обязательны | RULE:ID, возможны null-координаты | Каждый риск привязан к строке; правило можно объяснить в risk |
| Ошибки | LLM_ERROR, LLM_TIMEOUT, INVALID_REVIEW; 400 для входа | MODEL_UNAVAILABLE, MODEL_TIMEOUT, INVALID_MODEL_OUTPUT; отдельные 400/415/422 | Принять детальную таблицу логики; UI отобразит безопасные сообщения |
| retryable | Нет | Boolean в ошибке | Убрать; действие определяет фиксированная таблица UI |
| Дополнительные поля | UI игнорирует | Ответ модели строгий | Разные границы: модель строго, служебные поля UI допускает |
| Ожидание | 15 секунд UI | 10 секунд LLM | Совместимо; поздний ответ не меняет новый экран |
| Live/demo | Подмена явно обозначается | mode в ответе, без fallback | Явный mode, маркировка demo в UI |
| Размеры полей результата | Только непустые строки | Ограниченные длины и количество | Принять пределы логики, проверить форму в UI |
