# UI interface contract

Источник: [общий контракт v1.0](../../../../CONTRACT.md). Этот файл определяет клиентские точки интеграции, не создаёт вторую версию API.

## Документ и ресурсы

- GET / возвращает static/index.html; GET /static/app.js и /static/styles.css обслуживает backend.
- Клиент отправляет same-origin POST /api/reviews с Content-Type application/json и единственным полем diff.
- Доступные имена для интеграционных проверок: поле «Diff одного PR», кнопки «Проверить diff» и «Очистить», заголовки «Краткое описание», «Возможные риски», «Что проверить».
- Постоянный status region сообщает idle/loading/success; error region объявляет ошибку. Результат скрыт до корректного успеха. Loading блокирует textarea и обе кнопки.
- Счётчик N / 20 000 доступен через описание поля. Ошибка входа связана с полем; aria-invalid выставляется только при соответствующей ошибке.
- Режим demo: видимый текст «ДЕМО — воспроизводимая подмена модели». Live: «Реальный анализ». Приложение не переключает режим клиентским запросом.
- Динамические строки выводятся буквально; путь не превращается в ссылку. Координата подписана «новая версия» либо «старая версия» по evidence.
- Пустые risks: «Возможных рисков не найдено. Это не гарантирует отсутствие ошибок». Checks пустым быть не может.

## Таблица безопасных сообщений UI

| code | Пользовательское сообщение |
| --- | --- |
| UNSUPPORTED_MEDIA_TYPE / INVALID_JSON | Не удалось отправить запрос в ожидаемом формате. Повторите попытку. |
| INVALID_REQUEST | Проверьте ввод: нужен непустой diff одного PR. |
| DIFF_TOO_LARGE | Diff превышает лимит 20 000 символов. Сократите его и повторите. |
| INVALID_DIFF | Вставьте текстовый unified diff с изменёнными строками. |
| UNSUPPORTED_DIFF | Этот вид diff не поддерживается. Используйте обычный текстовый unified diff. |
| MODEL_NOT_CONFIGURED | Модель не настроена на сервере. Обратитесь к владельцу локального сервиса. |
| MODEL_TIMEOUT | Модель не ответила вовремя. Повторите попытку позже. |
| MODEL_UNAVAILABLE | Анализ сейчас недоступен. Повторите попытку позже. |
| INVALID_MODEL_OUTPUT | Получен некорректный результат. Повторите попытку. |
| INTERNAL_ERROR / неизвестный | Не удалось выполнить анализ. Повторите попытку или сообщите идентификатор запроса. |
| Локальная сеть | Не удалось связаться с сервисом. Проверьте подключение и повторите. |
| Локальное ожидание 15 секунд | Время ожидания истекло. Повторите попытку позже. |

Сырые server message, исключение, body и prompt не отражаются и не логируются. Корректный request_id можно показать текстом для диагностики. При неверном JSON успеха или нарушении data-model — локальное сообщение некорректного результата; частичный успех исключён.

## Владельцы границ

UI: форма, code point count, state machine, валидация формы результата, сообщения, доступность и literal rendering. Backend: parsing, secret masking, модель и timeout 10 секунд, окончательное доказательство, HTTP envelope, mode, request_id. Координатор: совместный запуск и Playwright, включая ошибки и поздние ответы.
