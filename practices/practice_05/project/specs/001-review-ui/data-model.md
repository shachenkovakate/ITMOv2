# Phase 1 data model — UI

Данные существуют только в памяти текущей страницы. Источник сетевой схемы — [CONTRACT v1.0](../../../CONTRACT.md). Ограничения строк считаются в Unicode code points; непустые текстовые поля также не могут состоять только из пробелов. Evidence не trim-ится: ведущий пробел — значимый префикс контекста.

## ReviewInput

- diff: строка, 1–20000 code points, не только пробельная; фактическое значение поля передаётся без преобразований.
- displayCount: вычисляемое число code points; не отправляется серверу.

## ReviewResult

- request_id: непустая строка; идентификатор попытки сервера.
- mode: только live или demo.
- summary: строка, 1–1500 code points, непустая после trim.
- risks: массив 0–3 Risk.
- checks: массив 1–10 строк, каждая 1–500 code points и непустая после trim.
- Дополнительные служебные поля верхнего уровня игнорируются.

## Risk

Ровно четыре поля: file, line, evidence, risk; отсутствие/лишнее поле или null недопустимы.

- file: непустая строка; нормализованный путь из diff проверяет backend.
- line: целое число > 0, boolean запрещён; для добавления/контекста новая нумерация, для удаления старая.
- evidence: строка 1–20000 code points, начинается с +, - или пробела; точное совпадение файла/координаты/очищенной строки проверяет backend.
- risk: строка 1–1000 code points, непустая после trim.

Сторона для отображения вычисляется по префиксу evidence; отдельное поле side не добавляется. Правило контекста может быть частью risk, но не заменяет evidence. Результат — возможный риск, не доказанный дефект.

## ReviewError

- error.code: строка из таблицы контракта либо неизвестный код → общий безопасный текст UI.
- error.message: серверная безопасная строка; UI её не отражает, использует свою таблицу.
- request_id: непустая строка при наличии корректного серверного ответа; при локальной ошибке/потере связи может отсутствовать.
- Неуспешный HTTP либо неверная форма успеха никогда не дают частичный результат.

## ViewState и Attempt

- ViewState: ровно idle, loading, success, error.
- Attempt: локальный монотонный номер, active, AbortController, таймер 15000 мс и снимок отправленного текста; не сохраняется.
- Единственный loading одновременно. Любая завершённая попытка становится inactive, её таймер очищается; запоздалые результаты игнорируются.

| Событие | Переход | Данные/действия |
| --- | --- | --- |
| Ввод/очистка вне loading | → idle | Удалить старые result/error; очистка также удаляет diff и фокусирует поле |
| Ошибка локальной проверки | → error | Сохранить diff, текст ошибки связать с полем, фокусировать поле |
| Допустимый submit | → loading | Очистить result/error; создать Attempt; заблокировать поле/кнопки |
| Корректный активный ответ | loading → success | Завершить Attempt, разблокировать, показать результат и mode |
| Ошибка/таймер активной попытки | loading → error | Завершить Attempt, разблокировать, сохранить diff |
| Поздний ответ завершённой попытки | без перехода | Игнорировать, не трогать данные и кнопки новой попытки |
