# Проверка интерфейса

Запуск из `practices/practice_05/project`: `REVIEW_MODE=demo make run`.
Установка зависимостей и браузера — в [RUN.md](../../RUN.md).
Автоматическая совместная проверка: `make e2e` или `make check`.

Проверяемые сценарии:

1. Учебный diff проходит через UI и реальный локальный API; выводятся три
   раздела результата и явный маркер ДЕМО.
2. Пустой ввод и 20001 символ отклоняются локально; 20000 Unicode code points
   доходят до сервера. Некорректный diff сохраняется для исправления и повтора.
3. Во время ожидания форма заблокирована, повторная отправка не создаёт запрос;
   поздний ответ после 15 секунд не заменяет результат новой попытки.
4. Неверная структура ответа отклоняется целиком, ошибки сети/сервера понятны,
   текст отображается буквально. Редактирование и очистка убирают старый результат.
5. Клавиатурная навигация, подписи DOM/ARIA, ширина 360 CSS px и reflow работают.
6. Заголовкоподобные строки diff сохраняют правильную привязку результата к файлу.

После последнего аудита: **11 browser tests — PASS**.
