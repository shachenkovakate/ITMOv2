# Проверка логики и API

Рабочий каталог: `practices/practice_05/project`. Установка зависимостей и
настройка окружения описаны в [RUN.md](../../RUN.md).
Контракт: [contracts/api.md](contracts/api.md).

```bash
make test
make coverage
REVIEW_MODE=demo make run
```

Проверяются учебный partial diff, координаты добавленных/удалённых строк,
0–3 риска и атомарный отказ при неверном результате, размер 20000/20001,
Unicode и CRLF, маскирование, схема ошибок, таймаут и отмена.
Сетевой адаптер проверяется через HTTPX MockTransport; внешний LLM не вызывается.
Production deadline — 10 секунд; короткий deadline применяется только внутри теста.

После последнего аудита: **42 unit/API tests — PASS**, покрытие backend
с ветвлениями — **94%**. Исходные и дополнительные регрессии:
[результаты ревью](../../../evidence/review-findings.md).
Актуальный общий прогон: [final-check.txt](../../../evidence/final-check.txt),
покрытие: [logic-coverage.txt](../../../evidence/logic-coverage.txt).

Через интерфейс проверяются учебный diff, понятный отказ для некорректного
ввода и повторный запуск. Совместная проверка: `make check`.
Все 14 задач логики реализованы; реальный вызов модели и качество её рекомендаций
этими тестами не подтверждаются.
